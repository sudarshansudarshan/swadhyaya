Sushruta's Vector Hunt — Find all [x; y] with [1 1][x; y] = 0

We want every column-vector v = [x; y] that the matrix M = [1 1] sends to zero. Multiply M by v: Mv = 1·x + 1·y. We need this to be zero — so x + y = 0. Find all (x, y) that work.

1  1 · x y = 0 ⟺ x + y = 0 ⟺ y = −x

Bhavabhuti's Singular Map — B = [[1, 2], [2, 4]]

B is a singular matrix (det(B) = 0). Its columns (1, 2) and (2, 4) are linearly dependent — both point along the same direction (1, 2). The line 2y + x = c (a family of parallel lines) maps under B to the single point (c, 2c). Every whole line collapses to a single point along the image line y = 2x.

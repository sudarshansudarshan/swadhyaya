A is a function: one input → one output. Since det A = −1 ≠ 0, it's invertible — you can uniquely recover the input from the output.
A = [[2, 3], [3, 4]] acts on (x, y) to give (2x+3y, 3x+4y) · det = −1 · A⁻¹ = 1/(−1) · [[4, −3], [−3, 2]] = [[−4, 3], [3, −2]]

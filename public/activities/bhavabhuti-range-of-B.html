Bhavabhuti's Range — What does B actually output?

For any function B: ℝ² → ℝ², the range is the set of all possible outputs — { B(x, y) | (x, y) ∈ ℝ² }. For B = ((1, 2), (2, 4)), the two columns are linearly dependent (column 2 = 2 × column 1). So B collapses the whole plane onto something smaller. What is it?

The range is a line, not the whole plane. Type any (x, y) — every output lies on the range line. The kernel is the line of inputs that map to (0, 0).

The range of B
range(B) = { (t, 2t) | t ∈ ℝ } = the line y = 2x through the origin
This is a 1-dimensional subset of ℝ². Even though B takes a 2D input, B's output lives on a single line.

Think about the inverse

A function f is invertible if every output y comes from exactly one input x.

1. Is f(x) = 3x + 2 invertible?

2. If f(x) = 3x + 2 and f(α) = 17, what is α?

3. Is the answer α = 5 unique? Could another input also give 17?

4. What's the method to find α from f(α) = y?

5. Is it always possible to reverse y = ax + b for any target y?
